# heatmap.plus

Draws heatmaps with row and column annotations.

Compatibility updates by Renova.

Declares graphics and statistics imports, documents the function signature, and modernizes package metadata.

## Installation

```r
install.packages("heatmap.plus", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `1.3.9001` is based on [CRAN 1.3](https://cran.r-project.org/package=heatmap.plus).
